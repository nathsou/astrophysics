# GPT-2 tokeniser files

`vocab.bpe` (merge ranks) and `encoder.json` (token → id) of OpenAI's GPT-2 byte-level BPE tokeniser,
downloaded from `https://openaipublic.blob.core.windows.net/gpt-2/encodings/main/`.
