---
title: Cutting a cylinder parallel to its base
---
**Statement.** A plane parallel to the bases cuts a cylinder into two cylinders that are as their axes:
$$\text{cylinder } BG : \text{cylinder } GD = EK : KF.$$

**Proof.** This is a direct application of Eudoxus's definition of proportion ([[5.def.5]]), with no exhaustion. Take any multiples: lay off $EN$, $NL$, … each equal to @EK, $m$ times in all, and $FO$, $OM$, … each equal to @KF, $n$ times. The cylinders on equal axes over the same base are equal ([[12.11]]), so the cylinder @solid(QG) on the axis $KL = m \cdot EK$ is $m$ times @solid(BG), and the cylinder @solid(WG) on $KM = n \cdot KF$ is $n$ times @solid(GD). A longer axis gives a larger cylinder. So for all $m, n$,
$$m\cdot EK \gtreqless n\cdot KF \iff m\cdot BG \gtreqless n\cdot GD,$$
which is exactly what Definition V.5 requires for $EK : KF = BG : GD$.

**In the figure.** The slider moves the cutting plane @GH. The figure shows $m = n = 3$: the extended cylinder @solid(PW) with the planes through @N and @O. Each cylinder is named, as in Heath's figure, by a diagonal of its section through the axis.

:::code The definition as a test
Definition V.5 says two ratios are equal when no pair of multipliers can tell them apart. For the axes and cylinders here:

```ts
const sameRatio = (a, b, c, d) =>
  allPairs((m, n) =>
    Math.sign(m * a - n * b) === Math.sign(m * c - n * d));
```

Euclid's proof shows the test passes for every $(m, n)$, because the cylinders are built from equal slices exactly as the axes are.
:::
