---
title: Parallel through a point
---
**Construction.** Given a line $BC$ and a point $A$ not on it, draw a line through $A$ parallel to $BC$:

1. choose any point @point(D) on @BC and join @AD;
2. at @point(A), copy the angle @angle(ADC) onto @DA, on the other side of it from @point(C) ([[1.23]]). This gives $\angle DAE = \angle ADC$;
3. produce @EA to @point(F).

**Why it works.** The transversal $AD$ makes equal alternate angles with $EF$ and $BC$, so $EF \parallel BC$ by [[1.27]].

:::gap Existence without Postulate 5
This construction uses only [[1.23]] and [[1.27]], both neutral. So in any neutral geometry, hyperbolic geometry included, every point off a line has at least one parallel through it. What fails in hyperbolic geometry is uniqueness. A different choice of $D$ would give a *different* parallel there. In the Euclidean plane [[1.29]] shows that every choice gives the same line. Drag @point(D) in the figure: the line @EF does not move.
:::

:::code Stable output
The construction takes a free choice (the point $D$) and returns something that does not depend on it. That independence is not automatic: it is a theorem, and it needs Postulate 5. It is like a hash function that you have to prove gives the same result whichever element of the input set you start from.
:::
