---
title: Copying a length to a point
---
**Statement.** Given a point $A$ and a segment $BC$, there is a point $L$ with $AL = BC$.

This looks trivial with a pair of compasses: set them to $BC$ and put the point on $A$. But Postulate 3 ([[1.post.3]]) only lets you draw a circle with a given centre *through a given point*. It does not let you carry a distance from one place to another. I.2 shows that the carrying can be done anyway.

**Construction.**

1. Build the equilateral triangle @triangle(DAB) on @AB ([[1.1]]).
2. Produce @DA and @DB beyond @A and @B ([[1.post.2]]).
3. Draw the circle with centre @B through @C. It meets @DB produced at @G, so $BG = BC$.
4. Draw the circle with centre @D through @G. It meets @DA produced at @L, so $DL = DG$.

**Why it works.** $DL = DG$ and $DA = DB$. Subtract ([[1.cn.3]]):
$$AL = DL - DA = DG - DB = BG = BC.$$

:::code An adapter over a weaker primitive
Postulate 3 gives you `circleThrough(centre, point)`. Every later proposition wants `circleWithRadius(centre, a, b)`, the circle with centre `centre` and radius $|ab|$. I.2 implements the second in terms of the first, so it can be used freely from now on:

```ts
function circleWithRadius(centre: Point, a: Point, b: Point): Circle {
  const L = copyLength(centre, a, b); // I.2: |centre L| = |a b|
  return circleThrough(centre, L);    // Postulate 3
}
```

This is why historians speak of Euclid's "collapsing compass". Whether Euclid meant it that way is not certain, but after I.2 the difference does not matter: the two tools draw the same circles.
:::

:::gap Unstated intersections
Steps 3 and 4 assume that a line through the centre of a circle, produced far enough, meets the circle. That needs a continuity principle, as the circles of [[1.1]] do. The subtraction also needs @A to lie between @D and @L. It does, because $DL = DG = DB + BG > DB = DA$, but Euclid does not say so. The proof also depends on the figure: if @A lies on @BC, or $A = B$, the drawing changes, and ancient commentators already listed such cases.
:::

**In the figure.** Drag @A, @B or @C. The copy @AL has the length of @BC wherever the three points are, although it usually points in a different direction.
