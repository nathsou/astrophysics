---
title: Converse of Pythagoras’ theorem
---
**Statement.** In a triangle $ABC$, if
$$BC^2 = BA^2 + AC^2,$$
then $\angle BAC$ is a right angle. As in [[1.47]], the squares are figures and "equal" means equal in area.

**Proof.** Build a right triangle to compare with. At @point(A) draw @AD at right angles to @AC, with $AD = AB$ ([[1.11]], [[1.3]]), and join @DC.

- The triangle $DAC$ has a right angle at $A$, so by [[1.47]]: $DC^2 = DA^2 + AC^2 = BA^2 + AC^2$.
- By hypothesis $BC^2 = BA^2 + AC^2$. So $DC^2 = BC^2$, and therefore $DC = BC$.
- Now triangles $DAC$ and $BAC$ have $DA = BA$, the common side $AC$, and $DC = BC$. By SSS ([[1.8]]), $\angle DAC = \angle BAC$. The first is right, so the second is too.

:::code Build a witness, then compare
The proof has a pattern programmers use for equality checks: build a reference object that certainly has the property, then show the given object agrees with it on every input that determines the result. The triangle $DAC$ is right by construction. SSS says that three sides determine a triangle, and the two triangles agree on all three. So they agree on the angle.

Numerically, the converse is the test everyone uses:

```ts
const isRightAngled = (a: number, b: number, c: number) => a * a + b * b === c * c; // exact for integers
isRightAngled(3, 4, 5);    // true
isRightAngled(20, 21, 29); // true
```

With floating-point lengths, compare with a tolerance. This is what the figure does for all its claims.
:::

:::gap From equal squares to equal sides
The step "$DC^2 = BC^2$, so $DC = BC$" is not proved in Book I. It is true: if $DC > BC$, a square on $BC$ can be placed inside the square on $DC$ at a common corner, as a proper part, so the squares would be unequal. But Euclid does not state or prove this. With lengths as real numbers, it is the fact that $x \mapsto x^2$ is injective on $x > 0$.
:::

**In the figure.** The triangle is built from lengths alone: the slider fixes $BA : BC$, and @point(A) is placed where $AC = \sqrt{BC^2 - BA^2}$. No angle is imposed. Yet the angle @angle(BAC) comes out right, and @point(D) lands on @BA produced, as the reflection of @point(B) in @AC.

:::leads Where it leads
Book I ends here. It closes with Pythagoras' theorem and its converse, so together they give a test: a triangle has a right angle *if and only if* its sides satisfy $a^2 + b^2 = c^2$. [[2.12]] and [[2.13]] extend this: the angle opposite $c$ is obtuse exactly when $c^2 > a^2 + b^2$, and acute exactly when $c^2 < a^2 + b^2$. Together with I.47 and I.48 this is the law of cosines, stated without cosines.
:::
