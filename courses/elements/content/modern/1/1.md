---
title: Equilateral triangle on a segment
---
**Statement.** Given a segment $AB$, there is a point $C$ with $CA = CB = AB$. Euclid also gives the recipe for finding it:

1. draw the circle with centre @A through @B, and the circle with centre @B through @A ([[1.post.3]]);
2. let @C be a point where they meet;
3. join @CA and @CB ([[1.post.1]]).

**Why it works.** $C$ is on the first circle, so $AC = AB$, since all radii of a circle are equal ([[1.def.15]]). $C$ is on the second circle, so $BC = BA$. Two things equal to the same thing are equal to each other ([[1.cn.1]]), so $CA = CB$. All three sides are equal.

:::code A construction is a program
Read the proposition as a function with a type signature and a body:

```ts
function equilateralTriangle(A: Point, B: Point): Point {
  const k1 = circle(A, B);          // Postulate 3
  const k2 = circle(B, A);          // Postulate 3
  const [C] = intersect(k1, k2);    // ← not justified by any postulate
  return C;                         // |CA| = |CB| = |AB|
}
```

The postulates are the primitive operations, and each proposition becomes a library function the later ones call. I.2 calls this one, and I.2 is called almost everywhere. The [workshop](#/workshop) lets you build that library yourself.
:::

:::gap Why do the circles meet?
None of Euclid's postulates says that two circles meet. Here it seems obvious: each circle passes through the other's centre. But "obvious from the picture" is not a proof. In the plane of *rational* points, $\mathbb{Q}^2$, the circles centred at $(0,0)$ and $(1,0)$ through each other's centres meet at $(\tfrac12, \pm\tfrac{\sqrt3}{2})$, and neither point is in $\mathbb{Q}^2$. So there, the construction fails.

Modern axiomatizations close the gap with a continuity axiom. Hilbert used Dedekind completeness; for Euclid's constructions the weaker *circle–circle intersection property* is enough: if one circle passes through a point inside and a point outside another, the two circles meet.
:::

**In the figure.** Drag @A or @B. The triangle stays equilateral, because it is recomputed from the construction and not drawn once. Of the two points where the circles meet, @C is the one on the left of $\overrightarrow{AB}$. The other would give an equilateral triangle on the other side.

:::leads Where it leads
This is the first construction in the Elements, and the tool I.2 needs to copy a length. With the circle's symmetry, it also gives the regular hexagon ([[4.15]]): six of these triangles fit around a point.
:::
