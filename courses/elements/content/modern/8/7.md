---
title: If the first term divides the last
---
**Statement.** If $a_0, \dots, a_n$ are in continued proportion and $a_0 \mid a_n$, then $a_0 \mid a_1$.

**Proof.** This is the contrapositive of [[8.6]]. If @A did not divide @B, no term would divide a later one, but $A$ divides @D.

In modern terms: $a_n / a_0 = (q/p)^n$ in lowest terms, which is a whole number only if $p = 1$. Then the ratio is $1 : q$ and each term is $q$ times the one before. So $a_0$ divides every term, not only the second. In the figure the progression is $k, kr, kr^2, kr^3$, and the grey marks show $A$ fitting into $B$ and into $D$.

This small lemma is the lever for [[8.14]] and [[8.15]]: if $c^2 \mid d^2$, apply it to the progression $c^2, cd, d^2$.
