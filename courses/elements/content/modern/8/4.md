---
title: Chaining ratios with least common multiples
---
**Statement.** Given ratios $a : b$, $c : d$, $e : f$, each in least terms, find the least numbers $x_0, x_1, x_2, x_3$ with
$$x_0 : x_1 = a : b, \qquad x_1 : x_2 = c : d, \qquad x_2 : x_3 = e : f.$$
Euclid treats three ratios; the method works for any number.

**Construction.** The middle term $x_1$ must be a multiple of $b$ (for the first ratio) and of $c$ (for the second). So take @G $= \operatorname{lcm}(B, C)$ ([[7.34]]), and scale: @H $= A \cdot G / B$ and @K $= D \cdot G / C$. Then $H, G, K$ are in the ratios $A : B$ and $C : D$.

Now add the third ratio. The term @K must also be a multiple of @E.

- *First case*: $E \mid K$. Put @L $= F \cdot K / E$, and $H, G, K, L$ is the answer.
- *Second case*: $E \nmid K$. Take @M $= \operatorname{lcm}(E, K)$, scale everything built so far by $M / K$ to get @N, @O, @M, and put @P $= F \cdot M / E$.

The figure shows the second case by default. Change the sliders until $E$ divides $K$ and the rod $L$ becomes a whole number: then $N, O, M, P$ coincide with $H, G, K, L$.

**Why it is least.** Let $Q, R, S, T$ be any numbers in the same ratios. By [[7.20]], $B \mid R$ and $C \mid R$, so $\operatorname{lcm}(B, C) = G$ divides $R$ ([[7.35]]). The same argument moves along the chain: $K \mid S$ and $E \mid S$, so $M \mid S$. Therefore no progression in these ratios has a term below the one constructed, and the dashed @Q, @R, @S, @T cannot be smaller.

:::code A fold over the ratios
Euclid's two cases are one case in code, since $\operatorname{lcm}(E, K) = K$ when $E \mid K$:

```ts
// The least x0, x1, …, xn with x_i : x_{i+1} = r_i (each ratio in least terms).
function chain(ratios: [number, number][]): number[] {
  let xs = [...ratios[0]];
  for (const [c, d] of ratios.slice(1)) {
    const last = xs[xs.length - 1];
    const m = lcm(last, c);            // the next shared term
    xs = xs.map((x) => x * (m / last)); // rescale what we have
    xs.push(d * (m / c));
  }
  return xs;
}

chain([[2, 3], [4, 5], [2, 3]]); // [16, 24, 30, 45]
```
It is the same move as putting fractions over a common denominator: $\frac ab$ and $\frac cd$ are made to share the term $\operatorname{lcm}(b, c)$ before they are combined. [[10.12]] uses this proposition to chain two commensurable ratios.
:::
