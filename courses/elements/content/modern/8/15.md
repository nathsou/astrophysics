---
title: Cubes divide iff their sides divide
---
**Statement.** For numbers $c, d$:
$$c^3 \mid d^3 \iff c \mid d.$$

**Proof.** The same as [[8.14]], with two means instead of one. Build @E $= C^2$, @F $= CD$, @G $= D^2$, and @H $= C \cdot F$, @K $= D \cdot F$. Then @A, $H$, $K$, @B is a progression in the ratio @C : @D ([[8.11]], [[8.12]]). If $A \mid B$, the first term divides the last, so it divides the second ([[8.7]]): $A \mid H$. Since $A : H = C : D$, we get $C \mid D$.

Conversely, if $C \mid D$ then $A \mid H$, $H \mid K$, $K \mid B$ (each step is in the ratio $C : D$), so $A \mid B$.

With the defaults, $8 \mid 64$ and $2 \mid 4$. Set $C = 2$, $D = 6$ and then $D = 5$ to see both sides change together.

In terms of prime exponents (see [[8.14]]), cubing triples every exponent, which does not change any comparison $\alpha_p \le \beta_p$. The general statement, $c^k \mid d^k \iff c \mid d$, would follow in the same way from a progression with $k - 1$ means, but Euclid stops at cubes. Squares and cubes are the only powers with a name in his geometry.
