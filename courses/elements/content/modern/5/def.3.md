---
title: Ratio
---
**Definition.** A *ratio* is a relation in respect of size between two magnitudes of the same kind.

This is a description, not a definition: it says what a ratio is about, and never says what it is. The theory does not need it. Euclid only ever uses *same ratio* ([[5.def.5]]) and *greater ratio* ([[5.def.7]]), both defined by comparing multiples. That is the modern way to handle an abstract type: define the equality and the order relation, and never inspect the values.

The one hard requirement is "of the same kind": a line has a ratio to a line and an area to an area, but a line has no ratio to an area, because they cannot be compared.
