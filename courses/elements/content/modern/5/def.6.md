---
title: Proportional
---
**Definition.** Four magnitudes $a, b, c, d$ are *proportional* when $a : b = c : d$ in the sense of [[5.def.5]]. This is written $a : b = c : d$, or in older texts $a : b :: c : d$.

A proportion is a relation between four terms, not an equation between two numbers. Euclid never writes $\frac ab = \frac cd$, and with reason: $a/b$ would require dividing magnitudes, an operation he does not have. The modern equation is justified by Book V itself, which proves that "same ratio" behaves like equality of fractions.
