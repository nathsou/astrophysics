---
title: Remainder to remainder
---
**Statement.** If $AB : CD = AE : CF$, where $AE$ is part of $AB$ and $CF$ part of $CD$, then
$$EB : FD = AB : CD.$$
For fractions: if $\frac ac = \frac bd$ with $b < a$, $d < c$, then $\frac{a - b}{c - d}$ has the same value.

**Proof.** Alternate ([[5.16]]): $AB : AE = CD : CF$. Separate ([[5.17]]): $EB : EA = FD : FC$. Alternate again: $EB : FD = EA : FC$. And $EA : FC = AB : CD$ by hypothesis, so $EB : FD = AB : CD$ ([[5.11]]).

**Porism** (*convertendo*, [[5.def.16]]). If $a : b = c : d$, then $a : (a - b) = c : (c - d)$. It follows by separating, inverting and composing. The figure checks it as $AB : AE = CD : CF$.

This is the subtractive counterpart of [[5.12]], and it is used in [[5.25]]. Note the double use of alternation: the proof needs all four magnitudes to be of one kind.
