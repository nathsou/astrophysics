---
title: Composition (componendo)
---
**Statement.** If $AE : EB = CF : FD$, then
$$AB : BE = CD : FD.$$
With $a = AE$, $b = EB$, $c = CF$, $d = FD$: $a : b = c : d \Rightarrow (a + b) : b = (c + d) : d$. For fractions, add 1 to both sides.

**Proof** (by contradiction). Suppose $CD : DF \ne AB : BE$. Let $DG$ be the magnitude such that $AB : BE = CD : DG$, and suppose first $DG < DF$ (the figure draws this supposed @G between @F and @D). By separation ([[5.17]]), $AE : EB = CG : GD$. With the hypothesis and [[5.11]], $CG : GD = CF : FD$. But @CG $>$ @CF, so by [[5.14]] $GD > FD$, while we assumed $GD < FD$. The case $DG > DF$ is refuted in the same way. So $DG = DF$.

:::gap The fourth proportional
The proof begins: "let $CD$ be to some magnitude $DG$ as $AB$ is to $BE$". Nothing in Book V says that such a $DG$ exists. Euclid is assuming that for any $a, b$ and $c$ (with $c$ of a given kind) there is a $d$ with $a : b = c : d$. For straight lines he constructs it later, in [[6.12]]. For magnitudes in general it is an extra axiom: it says that each kind of magnitude contains a magnitude for every ratio that occurs. It can be avoided here. A direct proof from [[5.def.5]] is short: for $n > m$, $m(a + b) \gtrless nb$ is the same comparison as $ma \gtrless (n - m)b$, and for $n \le m$ both $m(a + b) > nb$ and $m(c + d) > nd$ hold trivially.
:::

:::code Order of the book
[[5.17]] (separando) is proved first and directly; this converse is proved from it by contradiction. It is like proving that a function is injective and then deriving the inverse property from it. The contradiction argument is shorter, but it needs the existence of the object it refutes.
:::
