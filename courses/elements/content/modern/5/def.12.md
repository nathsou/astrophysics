---
title: Alternate ratio (alternando)
---
**Definition.** From $a : b = c : d$, taking *alternately* means passing to $a : c = b : d$: antecedent to antecedent, consequent to consequent.

For fractions, $\frac ab = \frac cd \Rightarrow \frac ac = \frac bd$. It is proved in [[5.16]], and only makes sense when all four magnitudes are of the same kind, since $a : c$ must be a ratio.
