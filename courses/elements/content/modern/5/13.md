---
title: Substituting in an inequality of ratios
---
**Statement.** If $a : b = c : d$ and $c : d > e : f$, then $a : b > e : f$.

**Proof.** By [[5.def.7]] there are multipliers $m, n$ with $G = mC > K = nD$ but $H = mE \le L = nF$ (@G, @K, @H, @L in the figure, which finds the least such $m$). Take the same multipliers for the first ratio: $M = mA$ and $N = nB$. Since $a : b = c : d$ and $G > K$, [[5.def.5]] gives $M > N$. So the pair $(m, n)$ has $mA > nB$ while $mE \le nF$: a witness that $a : b > e : f$.

This is the rule "equals may be substituted in an inequality" for ratios, one of the facts that make $>$ on ratios behave like an order. The companion case, $a : b > c : d$ and $c : d = e : f$ giving $a : b > e : f$, is proved the same way; Euclid does not state it.
