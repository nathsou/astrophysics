---
title: A greater magnitude has a greater ratio
---
**Statement.** If $a > b$, then for any $d$ (of the same kind),
$$a : d > b : d \qquad\text{and}\qquad d : b > d : a.$$
By [[5.def.7]] this means finding whole numbers $k, j$ with $ka > jd$ but $kb \le jd$.

**Proof** (Heath's first case). Write $a = AB$, $b = C$, and cut off $BE = C$, so the excess is $AE = a - b$. The key step is the Archimedean property ([[5.def.4]]): some multiple of the small excess exceeds @D. Let @FG $= k \cdot AE$ be such a multiple, and put @GH $= k \cdot EB$ and @K $= k \cdot C$, so $GH = K$ and $FH = k \cdot AB$ ([[5.1]]). Now step through the multiples of $D$: @L $= 2D$, $3D$, … and let @N $= jD$ be the first that exceeds @K, with @M the one before it. Then $K \ge M$, so
$$FH = FG + GH > D + M = N, \qquad\text{while}\qquad K < N.$$
So $k \cdot AB > j \cdot D$ but $k \cdot C \le j \cdot D$, which is $AB : D > C : D$. The same pair $(k, j)$, read the other way, gives $D : C > D : AB$.

The second case, $AE > EB$, multiplies the smaller piece @EB instead; Euclid sketches it.

:::gap Euclid's hidden axioms
Two assumptions carry the proof. The Archimedean property is used as a fact, although [[5.def.4]] is phrased as a definition. And "the first multiple of $D$ greater than $K$" uses the well-ordering of the whole numbers: the least element of a nonempty set of numbers. Both are sound, and both are axioms in any modern treatment of the reals.
:::

:::code Finding the witness
```ts
// integers (k, j) with k·a > j·d ≥ k·b, for a > b
function witness(a: number, b: number, d: number): [number, number] {
  const k = Math.floor(d / (a - b)) + 1; // k·(a − b) > d   (Archimedes)
  const j = Math.floor((k * b) / d) + 1; // first multiple of d above k·b
  return [k, j];                         // k·a ≥ k·b + (a − b)·k > j·d
}
```
The figure computes these numbers live: $k$ is the number of copies in @FG, and $j$ is the number of copies of $D$ in @N.
:::
