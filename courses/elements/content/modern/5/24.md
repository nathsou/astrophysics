---
title: Adding ratios with the same consequent
---
**Statement.** If $AB : C = DE : F$ and $BG : C = EH : F$, then
$$AG : C = DH : F,$$
that is, $(a + b) : c = (d + e) : f$ whenever $a : c = d : f$ and $b : c = e : f$. For fractions: $\frac ac + \frac bc = \frac{a + b}c$.

**Proof.** Invert the second hypothesis: $C : BG = F : EH$. Combine with the first ex aequali ([[5.22]]): $AB : BG = DE : EH$. Compose ([[5.18]]): $AG : GB = DH : HE$. Combine ex aequali with $BG : C = EH : F$: $AG : C = DH : F$.

This is the addition of ratios, in the only form Euclid can state it: two ratios with the same consequent. The proof uses the fourth-proportional assumption through [[5.18]]. The figure computes @F and @EH from the hypotheses and checks the conclusion for any @AB, @BG, @C and @DE.
