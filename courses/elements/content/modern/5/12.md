---
title: Sum of antecedents to sum of consequents
---
**Statement.** If $a : b = c : d = e : f$, then
$$a : b = (a + c + e) : (b + d + f).$$
For fractions: if $\frac ab = \frac cd = \frac ef$, the *mediant* $\frac{a + c + e}{b + d + f}$ has the same value.

**Proof.** Take equimultiples @G, @H, @K $= mA, mC, mE$ and @L, @M, @N $= nB, nD, nF$. By hypothesis the comparisons $G \gtrless L$, $H \gtrless M$, $K \gtrless N$ all come out alike. If each of $G, H, K$ exceeds its partner, the sum $G + H + K$ exceeds $L + M + N$, and likewise for equal and less. By [[5.1]], $G + H + K = m\,(A + C + E)$ and $L + M + N = n\,(B + D + F)$. So $mA \gtrless nB$ and $m(A + C + E) \gtrless n(B + D + F)$ agree for all $m, n$, which is the claim by [[5.def.5]].

The proposition needs all six magnitudes to be of one kind, so that the sums exist. [[5.15]] and [[5.24]] use it.
