---
title: Perturbed ex aequali, the order lemma
---
**Statement.** Let $a : b = e : f$ and $b : c = d : e$ (a *perturbed* proportion, [[5.def.18]]). Then
$$a > c \iff d > f, \qquad a = c \iff d = f, \qquad a < c \iff d < f.$$

**Proof.** Suppose @A $>$ @C. By [[5.8]], $A : B > C : B$. By hypothesis $A : B = E : F$, and inverting the second hypothesis gives $C : B = E : D$. So $E : F > E : D$ ([[5.13]]). The same magnitude has a greater ratio to the smaller one ([[5.10]]), so $F < D$. The other cases are the same.

This is the lemma for [[5.23]], exactly as [[5.20]] is the lemma for [[5.22]]. In fractions, $\frac df = \frac de \cdot \frac ef = \frac bc \cdot \frac ab = \frac ac$, so $d \gtrless f$ matches $a \gtrless c$.
