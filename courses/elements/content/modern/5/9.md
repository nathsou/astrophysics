---
title: Same ratio to the same means equal
---
**Statement.** If $a : c = b : c$, then $a = b$. If $c : a = c : b$, then $a = b$.

**Proof.** If $a \ne b$, say $a > b$, then $a : c > b : c$ by [[5.8]], which contradicts $a : c = b : c$. The second statement is the same, using the second half of [[5.8]].

This is the converse of [[5.7]]: a ratio to a fixed $c$ determines the magnitude. For fractions it is cancellation, $\frac ac = \frac bc \Rightarrow a = b$.

The figure shows the contrapositive. Make @A and @B different, and it finds whole numbers $m, n$ with $mA$ and $mB$ on opposite sides of $n\,C$: a pair that separates the two ratios. Make them equal and no such pair exists.

:::gap Greater and equal exclude each other
The step "$a : c > b : c$, but it is the same ratio, which is impossible" needs a ratio not to be both greater than and equal to another. That follows from [[5.def.5]] and [[5.def.7]] at once (a witness of "greater" violates "same"), but Euclid never states it.
:::
