---
title: Comparing across a proportion
---
**Statement.** If $a : b = c : d$ (all four of one kind), then
$$a > c \iff b > d, \qquad a = c \iff b = d, \qquad a < c \iff b < d.$$

**Proof.** Suppose @A $>$ @C. By [[5.8]], $A : B > C : B$. Since $A : B = C : D$, [[5.13]] gives $C : D > C : B$. A magnitude to which the same has a greater ratio is the smaller ([[5.10]]), so $D < B$. The other cases are similar; for equality, $A = C$ gives $C : D = A : B = C : B$ and $D = B$ by [[5.9]].

For fractions this is immediate: $\frac ab = \frac cd$ gives $\frac ac = \frac bd$, and a ratio of positive quantities is greater than 1 exactly when its numerator is larger. But that argument uses alternation, which Euclid has not yet proved: this proposition is the lemma he needs for it, in [[5.16]].
