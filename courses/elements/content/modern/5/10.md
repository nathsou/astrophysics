---
title: A greater ratio means a greater magnitude
---
**Statement.** If $a : c > b : c$, then $a > b$. If $c : b > c : a$, then $b < a$.

**Proof.** By trichotomy $a$ is equal to $b$, less, or greater. If $a = b$, then $a : c = b : c$ ([[5.7]]), not greater. If $a < b$, then $a : c < b : c$ ([[5.8]]), not greater. So $a > b$. The second statement is proved in the same way.

With [[5.8]] this makes $x \mapsto x : c$ an order-preserving and order-reflecting map, and $x \mapsto c : x$ an order-reversing one. In the figure @A $> $ @B, and the readout gives the whole numbers $m, n$ that witness $A : C > B : C$ as in [[5.def.7]].

:::gap Trichotomy of ratios
The proof also uses that "less ratio" and "greater ratio" exclude each other, and that one of greater, equal and less always holds. Euclid states neither. Both follow from the definitions: in the language of [[5.def.5]], a ratio corresponds to a lower set of fractions, and such sets are totally ordered by inclusion.
:::
