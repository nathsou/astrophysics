---
title: Alternation (alternando)
---
**Statement.** If $a, b, c, d$ are of one kind and $a : b = c : d$, then
$$a : c = b : d.$$
For fractions this is one line: multiply $\frac ab = \frac cd$ by $\frac bc$. That line uses a product of ratios and the commutativity of multiplication, and Euclid has neither.

**Proof.** Take any multiples $E = mA$, $F = mB$ and $G = nC$, $H = nD$. By [[5.15]], $A : B = E : F$ and $C : D = G : H$; with the hypothesis and [[5.11]], $E : F = G : H$. Now [[5.14]] applies to this proportion: $E \gtrless G$ exactly when $F \gtrless H$. Since $E, F$ are equimultiples of $A, B$ and $G, H$ are equimultiples of $C, D$, this is precisely the test of [[5.def.5]] for $A : C = B : D$.

The figure shows it with @E, @F, @G, @H: whatever $m$ and $n$, the comparisons $E \gtrless G$ and $F \gtrless H$ agree.

:::gap All four of one kind
The ratio $a : c$ exists only if $a$ and $c$ are of the same kind ([[5.def.3]]). In a proportion such as "triangle : triangle = base : base" ([[6.1]]) alternation is meaningless. Euclid states the proposition for "four magnitudes" without the restriction.
:::

:::leads Where it leads
Alternation is the step that turns Euclid's ratios into numbers: once $a : b = c : d \Rightarrow a : c = b : d$ is available, a proportion behaves like an equation between fractions. Book VI uses it constantly, for instance to go from $AB : AD = AC : AE$ ([[6.2]]) to statements about corresponding sides of similar triangles ([[6.4]]).
:::
