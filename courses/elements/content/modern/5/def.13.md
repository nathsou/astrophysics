---
title: Inverse ratio (invertendo)
---
**Definition.** The *inverse* of the ratio $a : b$ is $b : a$. From $a : b = c : d$ one passes inversely to $b : a = d : c$.

In modern terms, $\frac ab = \frac cd \Rightarrow \frac ba = \frac dc$. Euclid proves it as the porism of [[5.7]]; the proof is immediate from [[5.def.5]], since $ma > nb$ is the same statement as $nb < ma$.
