---
title: Equal magnitudes have equal ratios
---
**Statement.** If $a = b$, then for any $c$,
$$a : c = b : c \qquad\text{and}\qquad c : a = c : b.$$

**Proof.** Take equimultiples @D $= mA$, @E $= mB$ and any multiple @F $= nC$. Since $A = B$, $D = E$, so $D$ and $E$ compare with $F$ in the same way. That is exactly [[5.def.5]] for $A : C = B : C$. For the second statement, compare $F$ with $D$ and with $E$ instead.

**Porism.** If $a : b = c : d$ then $b : a = d : c$ (*invertendo*, [[5.def.13]]). The reason is that $ma > nb$ and $nb < ma$ are the same fact, so the test for $b : a = d : c$ is the test for $a : b = c : d$ read backwards.

This is the substitution rule: equal magnitudes can replace each other inside a ratio. Euclid proves it rather than assuming it, because "same ratio" is a defined relation and only its definition may be used.
