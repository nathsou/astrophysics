---
title: Volumes of the same height are as the bases
---
**Statement.** Parallelepipeds @solid(AB) and @solid(CD) of the same height are to each other as their bases:
$$\text{solid } AB : \text{solid } CD = \text{base } AE : \text{base } CF.$$

**Proof (Euclid's).** Apply to the side @FG a parallelogram @figure(FH) equal to @figure(AE) ([[1.45]]), and complete the solid $GK$ on it with the height of @solid(CD). By [[11.31]], $GK = AB$ (equal bases, same height). The combined solid $CK$ is cut by the plane @plane(DG), parallel to two of its faces, so $CD : GK = CF : FH$ ([[11.25]]). Substitute $GK = AB$ and $FH = AE$ and invert.

:::code
With $V = B \cdot h$ and equal $h$, $V_1 : V_2 = B_1 : B_2$. Euclid's route to this formula passes through [[11.25]], so the ratio can be irrational: nothing assumes that the bases are commensurable.
:::
