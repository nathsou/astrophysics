---
title: Compound ratio of parallelograms
---
**Statement.** Equiangular parallelograms @figure(AC) and @figure(CF) are to one another in the ratio *compounded* of the ratios of their sides:
$$\text{▱}AC : \text{▱}CF = (BC : CG) \cdot (DC : CE).$$
In modern terms, area $= ab\sin\theta$, so for the same angle $\theta$ the ratio of the areas is $\dfrac{a}{a'}\cdot\dfrac{b}{b'}$.

**How Euclid compounds ratios without multiplying.** A Greek ratio is not a number, so the product of two ratios needs a definition. Euclid uses chains: choose any segment @K, find @L with $K : L = BC : CG$, then @M with $L : M = DC : CE$ (both by [[6.12]]). The ratio $K : M$ is *compounded* of $K : L$ and $L : M$, and so of the two ratios of sides. It does not depend on the choice of $K$.

**Proof.** Place the parallelograms with $BC$ in line with $CG$, so that $DC$ is in line with $CE$, and complete the parallelogram @figure(DG), which the text also calls $CH$.

- $AC$ and $CH$ have the same height, so $AC : CH = BC : CG = K : L$ ([[6.1]]).
- $CH$ and $CF$ have the same height, so $CH : CF = DC : CE = L : M$.
- *Ex aequali* ([[5.22]]), $AC : CF = K : M$.

The middle parallelogram $CH$ plays the role of $L$: it shares one side with each of the others.

:::code Ratios as a type
Euclid's ratios behave like a type without multiplication, where the only way to combine two values is through a chain with a shared middle term:

```ts
type Ratio = [Magnitude, Magnitude];
// compound(a:b, c:d) is K:M, where a:b = K:L and c:d = L:M
const compound = ([a, b]: Ratio, [c, d]: Ratio, K = 1): Ratio => {
  const L = (K * b) / a; // fourth proportional, VI.12
  const M = (L * d) / c;
  return [K, M];         // K/M = (a/b)·(c/d)
};
```

Once ratios are identified with positive real numbers, `compound` is plain multiplication. That identification is the modern definition of the real numbers by Dedekind cuts, which is [[5.def.5]] in disguise.
:::

:::leads Where it leads
The compound ratio is the ancestor of the product of real numbers, and this proposition is the ancestor of the rule "area = length × width". The duplicate ratio of [[6.19]] is the compound of a ratio with itself. Greek astronomy and Ptolemy's trigonometry used compound ratios heavily, for example in Menelaus' theorem.
:::
