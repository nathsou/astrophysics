---
title: Dividing a segment in a given ratio
---
**Construction.** Given the uncut segment @AB and a segment @AC cut at @D and @E, cut $AB$ in the same proportions. Place them at an angle at @A, join @CB, and draw @DF and @EG parallel to @CB. Then @F and @G cut $AB$ as $D$ and $E$ cut $AC$:
$$AF : FG : GB = AD : DE : EC.$$

**Why it works.** Draw @DK parallel to $AB$, cutting $EG$ at @H. The figures @figure(FH) and @figure(HB) are parallelograms, so $DH = FG$ and $HK = GB$ ([[1.34]]). In triangle $DKC$, $HE \parallel KC$, so $CE : ED = KH : HD = BG : GF$ ([[6.2]]). In triangle $AGE$, $FD \parallel GE$, so $ED : DA = GF : FA$.

This generalizes [[6.9]], which is the case of equal parts, and it works for any number of cuts. In modern terms it is linear interpolation: the parallels carry the parameter $t = AD/AC$ from one line to the other.

:::code The same thing in code
```ts
// cut AB at the same fractions as the cuts of AC
const cutLike = (A: Point, B: Point, cuts: number[] /* lengths along AC */, AC: number) =>
  cuts.map((d) => lerp(A, B, d / AC));
```
The geometry does this division $d / AC$ without numbers, and the result is the same even when the ratios are irrational.
:::
