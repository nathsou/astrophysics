---
title: Equal parallelograms have reciprocal sides
---
**Statement.** Let @figure(AB) and @figure(BC) be equiangular parallelograms with the equal angles at @B, placed so that @DB, @BE are in one line and @FB, @BG are in one line. Then
$$\text{▱}AB = \text{▱}BC \iff DB : BE = GB : BF.$$

In modern terms: for parallelograms with the same angle $\theta$, area $= ab\sin\theta$, and $ab = cd \iff a : c = d : b$.

**Proof (Euclid's).** Complete the parallelogram @figure(FE) on $FB$ and $BE$.

- $AB$ and $FE$ lie between the same two parallels (the line $DE$ and the parallel to it through $F$), so $AB : FE = DB : BE$ ([[6.1]]). In the same way $BC : FE = GB : BF$.
- If $AB = BC$, both have the same ratio to $FE$ ([[5.7]]), so $DB : BE = GB : BF$.
- Conversely, if $DB : BE = GB : BF$, then $AB : FE = BC : FE$ and $AB = BC$ ([[5.9]]).

The auxiliary parallelogram $FE$ is the common measuring stick: it shares one side with each of the two, so [[6.1]] compares each of them to it. The slider sets $BE : DB$; the figure makes $GB$ just long enough for the areas to be equal.
