---
title: Rationalising the denominator
---
**Statement.** With $\rho = 1$ and a rational line $A$: if $\sqrt X + \sqrt Y$ is a binomial, then
$$\frac{A^2}{\sqrt X + \sqrt Y} = \frac{A^2}{X - Y}\,\big(\sqrt X - \sqrt Y\big),$$
an apotome whose terms are commensurable with $\sqrt X$, $\sqrt Y$ and in the same ratio, and whose order is that of the binomial. Example: $\dfrac{4}{3 + \sqrt5} = 3 - \sqrt5$, a first apotome from a first binomial.

In the figure @BC $= BD + DC$ is the binomial, with greater term @DC, and @EF is the breadth of $A^2$ applied to $BC$.

**Proof (Euclid's).** Apply $A^2$ also to the lesser term: $BD \cdot G = A^2$, and lay off @EH $= G$. Since $BC \cdot EF = BD \cdot EH$,
$$CB : BD = HE : EF, \qquad\text{so, separando,}\qquad CD : DB = HF : FE \quad ([[5.17]]).$$
Now choose @K with $HF : FE = FK : KE$. Adding antecedents and consequents ([[5.12]]) gives $HK : KF = FK : KE = CD : DB$. So

- $HK$, $KF$, $KE$ are in continued proportion, hence $HK : KE = HK^2 : KF^2$, which is rational because $CD^2 : DB^2$ is. So @KE is commensurable with $HK$, and with $HE$ ([[10.15]]).
- $HE \cdot BD = A^2$ is rational, so $HE$ is rational and commensurable with $BD$ ([[10.20]]); therefore so is $EK$.
- $FK : KE = CD : DB$, with $CD$, $DB$ commensurable in square only, so $FK$, $KE$ are rational and commensurable in square only ([[10.11]]).

So $EF = FK - KE$ is an apotome. Its terms are proportional to $CD$ and $DB$, so [[10.14]], [[10.12]] and [[10.13]] carry every condition of the six definitions over from the binomial: the order is the same.

In algebra, the point $K$ is exactly where the factor $A^2/(X - Y)$ puts it: $FK = A^2\sqrt X/(X - Y)$ and $KE = A^2\sqrt Y/(X - Y)$.

:::code The conjugate trick
Multiply by the conjugate and the root leaves the denominator:
$$\frac{1}{\sqrt X + \sqrt Y} = \frac{\sqrt X - \sqrt Y}{(\sqrt X + \sqrt Y)(\sqrt X - \sqrt Y)} = \frac{\sqrt X - \sqrt Y}{X - Y}.$$
It is how inverses are computed in a quadratic field. Store $z = a + b\sqrt d$ as a pair of rationals:

```ts
type Q = Rational;
interface QSqrt { a: Q; b: Q }          // a + b·√d, for a fixed non-square d

const conj = (z: QSqrt): QSqrt => ({ a: z.a, b: z.b.neg() });
const norm = (z: QSqrt): Q => z.a.mul(z.a).sub(z.b.mul(z.b).mul(d));   // z · conj(z)
const inv  = (z: QSqrt): QSqrt => {
  const n = norm(z);                      // rational, and ≠ 0 since √d is irrational
  return { a: z.a.div(n), b: z.b.neg().div(n) };
};
```

Division never needs an irrational divisor; exact arithmetic stays exact. Euclid's proposition is `inv` for a binomial, together with the statement that `conj` preserves the order.
:::

:::leads Where it leads
The norm $z\,\bar z = X - Y$ is rational: [[10.114]] states it as "the rectangle on an apotome and its conjugate binomial has a rational side". [[10.113]] is the inverse of an apotome. Norms and conjugates, generalised from $\sqrt d$ to any algebraic number, are basic tools of algebraic number theory.
:::
