---
title: Greatest common measure of two magnitudes
---
**Statement.** Two commensurable magnitudes $a, b$ have a greatest common measure, found by Euclid's algorithm. **Porism:** every common measure of $a, b$ measures it.

**Proof.** This is [[7.2]] with magnitudes for numbers. Because $a$ and $b$ are commensurable, the subtraction must stop ([[10.2]]): here @AB measured along @CD leaves @EC, $EC$ measured along @AB (as @FB) leaves @AF, and $AF$ measures $EC$. Going back up the chain, @AF measures $FB$, so $AB$, so $ED$, so $CD$. It is a common measure.

If a greater @G measured both, going down the chain it would measure $EC$, then $FB$, then $AF$, a greater measuring a smaller. So $AF$ is the greatest. The same descent shows that every common measure divides $AF$: that is the porism.

With $AF$ as the unit, $AB$ and $CD$ are whole numbers with no common factor, which the figure checks. In modern terms: if $a/b = m/n$ in lowest terms, the greatest common measure is $a/m = b/n$.
