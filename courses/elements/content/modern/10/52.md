---
title: Constructing a fifth binomial
---
**Statement.** With numbers as in [[10.51]] ($AB$ in the ratio of two squares to neither $AC$ nor $CB$), set $EF^2 : FG^2 = CA : AB$. With $EF = 1$,
$$FG + EF = \sqrt{AB/AC} + 1$$
is a fifth binomial ([[10.def2.5]]). For $AC = 3$, $CB = 2$: $\sqrt{5/3} + 1$.

**Proof.** @EF and @FG are rational and commensurable in square only ([[10.9]]), so @EG is a binomial, now with $FG$ the greater term. If $FG^2 = EF^2 + H^2$, then $FG^2 : H^2 = AB : BC$ is not a ratio of squares, so @H is incommensurable with $FG$. The lesser term $EF$ is commensurable with the rational line @D, so $EG$ is a fifth binomial. This is [[10.49]] with the numbers of [[10.51]].
