---
title: The square root of a first binomial is a binomial
---
**Statement.** Let the rectangle @AC be contained by the rational line @AB $= 1$ and a first binomial @AD $= x + \sqrt Y$ ([[10.def2.1]]): $x$ is rational and $x^2 - Y = s^2$ for a rational $s$. Then the side of $AC$, the line whose square equals it, is a binomial. In algebra this is a *denesting* formula:
$$\sqrt{x + \sqrt Y} \;=\; \sqrt{\frac{x + s}{2}} + \sqrt{\frac{x - s}{2}}.$$
The figure's default is $AD = 3 + \sqrt5$, with $s = 2$: $\sqrt{3 + \sqrt5} = \sqrt{5/2} + \sqrt{1/2}$. Square the right side to check: $\tfrac52 + \tfrac12 + 2\sqrt{\tfrac54} = 3 + \sqrt5$.

**Proof (Euclid's).** The formula comes from solving $u + w = x$, $uw = Y/4$, and Euclid does exactly that with areas.

1. Cut @AD into its terms at @E, with $AE = x$ the greater, and bisect @ED at @F, so $EF = \sqrt Y / 2$.
2. Apply to @AE a rectangle $AG \cdot GE = EF^2$, deficient by a square ([[10.17]]). This splits $AE$ into $AG = u$ and $GE = w$, the roots of $t^2 - xt + Y/4 = 0$. Because $\sqrt{AE^2 - ED^2}$ is commensurable with $AE$, [[10.17]] says $AG$ and $GE$ are commensurable, and in fact both are rational: $u, w = (x \pm s)/2$.
3. Draw the rectangles @figure(AH) $= u$, @figure(GK) $= w$, @figure(EL) $= \sqrt Y/2$ on the rational line. Make squares @figure(SN) $= AH$ and @figure(NQ) $= GK$ ([[2.14]]) and place them corner to corner as in the lemma after [[10.53]].
4. From $AG : EF = EF : GE$, the rectangle $EL$ is the mean proportional between $AH$ and $GK$. So is @figure(MR) between $SN$ and $NQ$. Hence $EL = MR = PO$, and
$$AC = AH + GK + 2\,EL = SN + NQ + MR + PO = MO^2.$$
This is the square $SQ$ on $MO$. So @MO is the side of $AC$, and $MO = MN + NO = \sqrt u + \sqrt w$.
5. Classify. $AH$ and $GK$ are rational and commensurable, so @MN and @NO are rational and commensurable in square. $AG$ is incommensurable with $EF$ (because $AE$ is incommensurable with $ED$), so $SN$ is incommensurable with $MR$, and therefore $MN$ is incommensurable in length with $NO$ ([[6.1]], [[10.11]]). Two rational lines commensurable in square only: $MO$ is a binomial ([[10.36]]).

**The pattern.** [[10.54]]–[[10.59]] run this same construction on each of the six binomials, and the side $MO = MN + NO$ comes out as each of the six additive irrationals in turn:

| $AD$ | side of $\rho \cdot AD$ |
|---|---|
| first binomial | binomial (this proposition) |
| second binomial | first bimedial ([[10.55]]) |
| third binomial | second bimedial ([[10.56]]) |
| fourth binomial | major ([[10.57]]) |
| fifth binomial | side of a rational plus a medial area ([[10.58]]) |
| sixth binomial | side of the sum of two medial areas ([[10.59]]) |

What changes from row to row is only the arithmetic of step 5: whether $u$, $w$ are rational, medial or neither, and whether they are commensurable. [[10.60]]–[[10.65]] prove the converse, so the table is a one-to-one correspondence.

:::code Denesting as a function
```ts
// √(x + √Y) = √u + √w, with u, w rational
function denest(x: Rational, Y: Rational) {
  const s = rationalSqrt(x * x - Y); // or null
  if (s === null) return null;       // orders 4–6
  return [(x + s) / 2, (x - s) / 2]; // AG, GE
}
```
The figure runs this construction exactly: the readouts give $AG$, $GE$ and the sides $MN$, $NO$ as exact surds, and the claims check $AG \cdot GE = EF^2$, $MR = EL$ and $MO^2 = AC$.
:::

:::leads Where it leads
The condition "$x^2 - Y$ is a perfect square" is still the test for denesting $\sqrt{x + \sqrt Y}$ into a sum of two square roots of rationals. For example $\sqrt{5 + 2\sqrt6} = \sqrt3 + \sqrt2$, but $\sqrt{2 + \sqrt2}$ cannot be simplified this way, because $4 - 2 = 2$ is not a square. Computer algebra systems simplify nested radicals with this rule and its generalizations.
:::
