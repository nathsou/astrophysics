---
title: An apotome is never a binomial; the thirteen irrationals
---
**Statement.** No line is both an apotome and a binomial. With $\rho = 1$: if $X, Y$ are rationals with $X/Y$ not a square, and so are $U, V$, then
$$\sqrt X - \sqrt Y \ne \sqrt U + \sqrt V.$$

**Proof (Euclid's).** Suppose @AB is both. Apply its square to the rational line @DC, giving the breadth @DE.

- Because $AB$ is an apotome, $DE$ is a first apotome ([[10.97]]): $DE = DF - FE$ with $DF$, $FE$ rational, commensurable in square only, and $DF$ commensurable with $\rho$.
- Because $AB$ is a binomial, $DE$ is a first binomial ([[10.60]]): $DE = DG + GE$ with $DG$, $GE$ rational, commensurable in square only, and $DG$ commensurable with $\rho$.

$DF$ and $DG$ are both commensurable with $\rho$, so with each other, and their difference $GF$ is commensurable with $DF$ ([[10.15]]). Since $FE$ is incommensurable in length with $DF$, it is incommensurable with $GF$ too ([[10.13]]). So $GF$, $FE$ are rational lines commensurable in square only, and $GE = GF - FE$ is an apotome, which is irrational ([[10.73]]). But $GE$ is a term of a binomial, so it is rational. Contradiction.

**In modern terms.** Squaring moves the question into a single quadratic field. Both expansions give $DE = a - \sqrt b = c + \sqrt d$ with $a, c$ rational and $\sqrt b, \sqrt d$ irrational. Then $\sqrt b + \sqrt d = a - c$ is rational; squaring once more shows $\sqrt{bd}$ is rational, so $\sqrt d = r\sqrt b$ for a rational $r > 0$, and $a - c = (1 + r)\sqrt b$ would be irrational. The fact underneath is that $1$ and $\sqrt b$ are linearly independent over $\mathbb Q$: every number $p + q\sqrt b$ has only one such representation. Euclid proves the same thing with lines, and [[10.42]] and [[10.79]] are other versions of it.

**The thirteen irrational lines.** After this proof the text sums up the book: there are thirteen kinds of irrational straight line, and no line is of two kinds. With $\rho = 1$:

| | Line | Defined | Example | Its square |
|---|---|---|---|---|
| 1 | medial | [[10.21]] | $\sqrt[4]2$ | $\sqrt2$, incommensurable with $\rho$ |
| 2 | binomial | [[10.36]] | $\sqrt2 + 1$ | $3 + 2\sqrt2$, first binomial |
| 3 | first bimedial | [[10.37]] | $\sqrt[4]8 + \sqrt[4]2$ | $3\sqrt2 + 4$, second binomial |
| 4 | second bimedial | [[10.38]] | $\sqrt[4]{18} + \sqrt[4]2$ | $4\sqrt2 + 2\sqrt6$, third binomial |
| 5 | major | [[10.39]] | $\sqrt{1 + \frac{\sqrt2}{2}} + \sqrt{1 - \frac{\sqrt2}{2}}$ | $2 + \sqrt2$, fourth binomial |
| 6 | side of a rational plus a medial area | [[10.40]] | $\sqrt{\frac{\sqrt2 + 1}{2}} + \sqrt{\frac{\sqrt2 - 1}{2}}$ | $\sqrt2 + 1$, fifth binomial |
| 7 | side of the sum of two medial areas | [[10.41]] | $\sqrt{\frac{\sqrt3 + 1}{2}} + \sqrt{\frac{\sqrt3 - 1}{2}}$ | $\sqrt3 + \sqrt2$, sixth binomial |
| 8 | apotome | [[10.73]] | $\sqrt2 - 1$ | $3 - 2\sqrt2$, first apotome |
| 9 | first apotome of a medial | [[10.74]] | $\sqrt[4]8 - \sqrt[4]2$ | $3\sqrt2 - 4$, second apotome |
| 10 | second apotome of a medial | [[10.75]] | $\sqrt[4]{18} - \sqrt[4]2$ | $4\sqrt2 - 2\sqrt6$, third apotome |
| 11 | minor | [[10.76]] | $\sqrt{1 + \frac{\sqrt2}{2}} - \sqrt{1 - \frac{\sqrt2}{2}}$ | $2 - \sqrt2$, fourth apotome |
| 12 | produces with a rational area a medial whole | [[10.77]] | $\sqrt{\frac{\sqrt2 + 1}{2}} - \sqrt{\frac{\sqrt2 - 1}{2}}$ | $\sqrt2 - 1$, fifth apotome |
| 13 | produces with a medial area a medial whole | [[10.78]] | $\sqrt{\frac{\sqrt3 + 1}{2}} - \sqrt{\frac{\sqrt3 - 1}{2}}$ | $\sqrt3 - \sqrt2$, sixth apotome |

The last column is the whole argument. The square of each kind, applied to $\rho$, has a breadth of one definite type: a rational line incommensurable with $\rho$ for the medial ([[10.22]]), the $k$-th binomial for the $k$-th additive line ([[10.60]]–[[10.65]]), the $k$-th apotome for the $k$-th subtractive line ([[10.97]]–[[10.102]]). These thirteen types exclude one another: a binomial or an apotome is not rational, the six orders are defined by exclusive conditions, and by this proposition no binomial is an apotome. A line of two kinds would have a breadth of two types.

:::code A classifier with a proof of correctness
Read the table as a function from lines to tags:

```ts
type Kind = { tag: 'medial' } | { tag: 'additive' | 'subtractive'; order: 1 | 2 | 3 | 4 | 5 | 6 };

function kindOf(line: Line): Kind {
  const b = applyTo(rho, square(line));          // the breadth
  if (isRational(b)) return { tag: 'medial' };   // X.22: incommensurable with ρ
  if (isBinomial(b)) return { tag: 'additive', order: binomialOrder(b) };
  return { tag: 'subtractive', order: apotomeOrder(b) };
}
```

Book X proves that this function is well defined: each branch is reached by exactly the lines of that kind, and X.111 is the proof that the last two branches cannot both match. The figures of this book do the same check with exact arithmetic on sums $c_1\sqrt{n_1} + c_2\sqrt{n_2} + \dots$, never with floating-point guesses about irrationality.
:::

:::leads Where it leads
The binomial $\sqrt X + \sqrt Y$ and the apotome $\sqrt X - \sqrt Y$ are *conjugates*: the map $\sqrt Y \mapsto -\sqrt Y$ exchanges them, and [[10.112]]–[[10.114]] show that their product is rational. In the nineteenth century this symmetry became Galois theory, where the automorphisms of a field extension, not its individual elements, carry the structure. The thirteen lines themselves are a fragment of a larger picture: all of them are numbers constructible with ruler and compass, and [[10.115]] shows that even that fragment is infinite.
:::
