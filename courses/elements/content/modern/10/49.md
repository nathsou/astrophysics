---
title: Constructing a second binomial
---
**Statement.** With the same numbers as in [[10.48]] ($AB = m^2$, $BC = n^2$, $AC = m^2 - n^2$ not a square), set the ratio the other way round: $EF^2 : FG^2 = CA : AB$. With $EF = 1$,
$$FG + EF = \frac{m}{\sqrt{m^2 - n^2}} + 1$$
is a second binomial ([[10.def2.2]]). For $m = 3$, $n = 2$: $\tfrac{3}{\sqrt5} + 1$.

**Proof.** As in [[10.48]], @EF and @FG are rational and commensurable in square only, so @EG is a binomial. Now $FG$ is the greater term. If $FG^2 = EF^2 + H^2$, then $FG^2 : H^2 = AB : BC$, a ratio of squares, so @H is commensurable with $FG$ ([[10.9]]). The lesser term $EF$ is commensurable with the rational line @D. So $EG$ is a second binomial.
