---
title: The excess square scales with the lines
---
**Statement.** Let $a : b = c : d$, with $a^2 = b^2 + e^2$ and $c^2 = d^2 + f^2$. Then $a : e = c : f$. So $e$ is commensurable with $a$ exactly when $f$ is commensurable with $c$.

**Proof.** From $a : b = c : d$, $a^2 : b^2 = c^2 : d^2$ ([[6.22]]). Separating ([[5.17]]), $e^2 : b^2 = f^2 : d^2$, so $e : b = f : d$ ([[6.22]]). Combining with $a : b = c : d$ ex aequali ([[5.22]]) gives $a : e = c : f$, and [[10.11]] finishes.

In modern terms: if $c = ta$ and $d = tb$, then $f = \sqrt{c^2 - d^2} = t\sqrt{a^2 - b^2} = te$. The property "$\sqrt{a^2 - b^2}$ is commensurable with $a$" depends only on the ratio $a : b$. It is the property that separates the first three orders of binomials from the last three ([[10.def2.1]]).
