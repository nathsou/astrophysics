---
title: Euclid's algorithm detects incommensurability
---
**Statement.** Let $a > b$ be magnitudes. Run Euclid's algorithm on them: take $b$ from $a$ as often as possible, then the remainder from $b$, and so on. If no remainder ever measures the one before it, so that the process never stops, then $a$ and $b$ are incommensurable.

**Proof.** Suppose some magnitude @E measures both @AB and @CD. It then measures every remainder: $AB$ measured off along @CD as @FD leaves @CF, and $E$ divides $CD$ and $FD$, so it divides $CF = CD - FD$. In the same way it divides @BG, a multiple of $CF$, and so the next remainder @AG. Every remainder is a multiple of $E$.

But the remainders shrink: each is less than half of the one two steps before it, so by [[10.1]] some remainder, say $AG$, is less than $E$. A magnitude cannot measure one smaller than itself. So no common measure exists.

**In the figure.** $CD : AB = \sqrt n$. The quotients of the subtraction (how many times each remainder fits into the one before) are the *continued fraction* of $\sqrt n$. For $\sqrt 2$ they are $1, 2, 2, 2, \dots$: after the first step the picture repeats at a smaller scale, so it can never stop. For every non-square $n$ the quotients of $\sqrt n$ are eventually periodic (Lagrange proved this in 1770), which gives another proof that $\sqrt n$ is irrational.

::anthyphairesis{preset="diagonal : side"}

:::code The same loop as VII.2, with real inputs
```ts
// Anthyphairesis: the continued fraction of a/b (a, b > 0).
function* quotients(a: number, b: number) {
  while (b > 0) {
    const q = Math.floor(a / b);
    yield q;
    [a, b] = [b, a - q * b];
  }
}
```
For whole numbers the loop is Euclid's algorithm and terminates ([[7.2]]). For the side and diagonal of a square it would run for ever with exact arithmetic. With floating point it stops after a few dozen steps on rounding noise, which is why X.2 is a theorem and not a test you can run: the proof needs to know that the pattern repeats, not that it has lasted a while.
:::

:::gap Why the remainders get small
Euclid says only "let this process be repeated until there is left some magnitude less than $E$", citing nothing. The justification is [[10.1]]: if $r_{k+1} < r_k$ and $r_{k+2} = r_k - q\, r_{k+1}$ with $q \ge 1$, then $r_{k+2} \le r_k - r_{k+1}$ and also $r_{k+2} < r_{k+1}$, so $r_{k+2} < \tfrac12 r_k$. Taking more than half every second step is enough for X.1.
:::

:::history Anthyphairesis
The Greek word for this reciprocal subtraction is *anthyphairesis*. Aristotle mentions a definition of equal ratios by "the same antanairesis" (*Topics* VIII.3), and several historians have argued that an older theory of proportion compared ratios by their sequences of quotients, before Eudoxus' definition ([[5.def.5]]) replaced it. Book X keeps the algorithm only as a test of commensurability.
:::
