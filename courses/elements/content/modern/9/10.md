---
title: If the first power is not a square, only the even ones are
---
**Statement.** If $1, A, B, C, \dots$ are in continued proportion and $A$ is not a square, then the only squares among the terms are the ones [[9.8]] guarantees: $A^2, A^4, \dots$ If $A$ is not a cube, the only cubes are $A^3, A^6, \dots$

**Proof (squares).** Suppose @C $= A^3$ were a square. @B $= A^2$ is a square too, so $B : C$ is the ratio of a square to a square. But $B : C = A : B$, and $B$ is a square, so $A$ is a square ([[8.24]], with Euclid's own reference to [[8.26]]). This contradicts the hypothesis.

**Proof (cubes).** Suppose @D $= A^4$ were a cube. $C = A^3$ is a cube and $C : D = B : C$, so $B$ is a cube ([[8.25]]). $B = A^2$, so $A$ is a cube ([[9.6]]). This contradicts the hypothesis.

In exponents: if $A^k$ is a square with $k$ odd, then $A = A^k / (A^{(k-1)/2})^2$ is a square of a fraction, and hence a square.
