---
title: The square of a cube is a cube
---
**Statement.** If $A$ is a cube, then $A^2$ is a cube. In exponents: $(c^3)^2 = (c^2)^3$.

**Proof.** Let @C be the side of @A and let @D $= C^2$, so that $A = C \cdot D$. Each of these products gives a proportion with the unit ([[7.def.20]]):
$$1 : C = C : D = D : A.$$
So two means, $C$ and $D$, fall between the unit and $A$. Also $1 : A = A : B$, where @B $= A^2$. Numbers in the same ratio have the same number of means between them ([[8.8]]), so two means fall between $A$ and $B$ too. If four numbers are in continued proportion and the first is a cube, so is the last ([[8.23]]). So $B$ is a cube.

The means between $A = C^3$ and $B = C^6$ are $C^4$ and $C^5$. On the logarithmic scale of the figure, $1, C, D, A$ are equal steps, and so are $A$, the two means, and $B$.
