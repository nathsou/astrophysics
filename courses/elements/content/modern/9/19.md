---
title: When a fourth proportional exists
---
**Statement.** Given $A$, $B$, $C$, there is a number $E$ with $A : B = C : E$ exactly when $A \mid BC$, and then $E = BC / A$.

**Proof.** Let @D $= B \cdot C$. If $A \mid D$, say $D = A \cdot E$, then $A \cdot E = B \cdot C$, so $A : B = C : E$ ([[7.19]]). If $A \nmid D$ and @E existed, then $A \cdot E = B \cdot C = D$, so $A \mid D$. Contradiction.

Euclid organizes the proof in four cases: whether $A, B, C$ are in continued proportion, and whether the extremes $A, C$ are coprime. Only the divisibility test matters.

:::gap A wrong case
The second case (between the † marks in the text) claims that if $A, B, C$ are *not* in continued proportion and $A, C$ are coprime, there is no fourth proportional. That is false. Take $A = 2$, $B = 4$, $C = 3$: then $E = 6$ works, since $2 : 4 = 3 : 6$. The argument goes wrong when it introduces a number @E with $B : C = D : E$ without showing that such a number exists. The correct criterion is the one in the statement above. Set the sliders to $2, 4, 3$ to see the counterexample.
:::
