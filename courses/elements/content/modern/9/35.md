---
title: The sum of a geometric series
---
**Statement.** Let $a_1 < a_2 < \dots < a_n$ be in continued proportion. Then
$$\frac{a_2 - a_1}{a_1} = \frac{a_n - a_1}{a_1 + a_2 + \dots + a_{n-1}}.$$
"The excess of the second is to the first as the excess of the last is to all those before it." With $a_k = a r^{k-1}$ and $m = n - 1$, this is the familiar formula
$$\sum_{k=0}^{m-1} ar^k = a\,\frac{r^m - 1}{r - 1} \qquad (r \ne 1).$$

**Proof (the excess trick).** In the figure the terms are @A, @BC, @D, @EF. Mark off @FH $= A$, @FK $= BC$ and @FL $= D$ inside the last term $EF$, and @BG $= A$ inside $BC$.

1. The ratio of consecutive terms is constant: $EF : FL = LF : FK = FK : FH$, since these are $EF : D = D : BC = BC : A$.
2. Subtract the consequent from the antecedent in each ratio (*separando*, [[7.11]], [[7.13]]):
$$EL : LF = LK : FK = KH : FH.$$
Each antecedent is now a *difference of consecutive terms*: $EL = EF - D$, $LK = D - BC$, $KH = BC - A$.
3. When several ratios are equal, the sum of the antecedents is to the sum of the consequents in the same ratio ([[7.12]]):
$$KH : FH = (EL + LK + KH) : (LF + FK + FH).$$
4. The differences laid end to end *telescope* to @EH $= EF - A$. The consequents are $D + BC + A$. And $KH = GC$, $FH = A$. So $GC : A = EH : (A + BC + D)$.

With the default sliders, $8, 12, 18, 27$ (ratio $3 : 2$): $GC : A = 4 : 8$ and $EH : (8 + 12 + 18) = 19 : 38$, both $1 : 2$.

:::code Telescoping
The same idea as a loop invariant: every consecutive difference is $(r - 1)$ times the smaller term, so the differences add up to $(r-1)$ times the sum of all the terms but the last, while their total is the last term minus the first.
```ts
// Σ_{k<m} a·r^k without adding the terms: (a·r^m − a) / (r − 1), for r ≠ 1.
const geometricSum = (a: number, r: number, m: number) => (a * r ** m - a) / (r - 1);

// Euclid's form: (second − first) / first = (last − first) / (sum before last)
const terms = [8, 12, 18, 27];
const lhs = (terms[1] - terms[0]) / terms[0];
const rhs = (terms[3] - terms[0]) / (terms[0] + terms[1] + terms[2]); // both 0.5
```
In [[9.36]] the ratio is $2$, the excess of the second term is equal to the first, and the proposition gives $1 + 2 + 4 + \dots + 2^{n-1} = 2^n - 1$.
:::

:::leads Where it leads
This is the finite geometric sum. Archimedes used a relative of it, $1 + \tfrac14 + \tfrac1{16} + \dots$, to find the area of a parabolic segment. Letting $n \to \infty$ with $|r| < 1$ gives $\sum ar^k = a/(1 - r)$, the first infinite series most people meet. In computing, the same identity explains why doubling a dynamic array's capacity gives amortized constant-time appends: the copies made along the way add up to less than the final size.
:::
