---
title: When a third proportional exists
---
**Statement.** Given $A$ and $B$, there is a number $D$ with $A : B = B : D$ exactly when $A \mid B^2$, and then $D = B^2 / A$.

**Proof.** Let @C $= B^2$. If $A$ and $B$ are coprime, there is none ([[9.16]]). Otherwise:

- If $A \mid C$, say $C = A \cdot D$, then $A \cdot D = B \cdot B$, so $A : B = B : D$ ([[7.19]]).
- If $A \nmid C$ and @D existed, then $A \cdot D = B^2 = C$ ([[7.19]]), so $A \mid C$. Contradiction.

The coprime case is really part of the second case: coprime $A \ge 2$ never divides $B^2$. Euclid's "investigate" (the problem is to decide, not to construct) is a decision procedure. Move the sliders: $D$ is solid when it exists and dashed when it does not.
