---
title: Every composite number has a prime divisor
---
**Statement.** Every composite number $a$ is divisible by some prime.

**Proof.** Since @A is composite, some number @B divides it. If $B$ is prime, we are done. If not, some number @C divides $B$, and then $C$ divides $A$. If $C$ is prime, we are done; if not, continue. The process must end at a prime. Otherwise there would be an infinite sequence of numbers $A > B > C > \cdots$, each dividing the one before, "which is impossible in numbers".

:::gap Infinite descent
"Impossible in numbers" is the well-ordering principle: there is no infinite strictly decreasing sequence of positive integers. Euclid takes it as evident and states it only here, though [[7.1]] and [[7.2]] depend on it too. Fermat later made it a method of proof, *infinite descent*. For magnitudes it is false: [[10.1]] halves a magnitude as often as you like, and the process of [[10.2]] can go on for ever.
:::

:::code A loop and its variant
```ts
function primeDivisor(a: number): number {
  let d = a;                       // invariant: d divides a
  for (;;) {
    const f = properDivisor(d);    // some divisor 1 < f < d, or null if d is prime
    if (f === null) return d;
    d = f;                         // variant: d strictly decreases
  }
}
```
Euclid's paragraph is exactly a termination proof: the invariant says the answer is correct, and the variant says the loop stops. Choosing $f$ to be the *least* divisor greater than $1$ ends the loop at once, since the least divisor of $d$ greater than $1$ is always prime.
:::
