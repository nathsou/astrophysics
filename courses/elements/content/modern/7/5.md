title: Adding equal parts
---
**Statement.** If $a = \tfrac1n b$ and $c = \tfrac1n d$, then $a + c = \tfrac1n (b + d)$.

**Proof.** @BC consists of $n$ copies of @A (in the figure, @BG and @GC), and @EF of $n$ copies of @D (@EH and @HF). Pair them off: @BG with @EH, @GC with @HF. Each pair makes $a + c$, and there are $n$ pairs, so $b + d = n(a + c)$.

This is the distributive law $n a + n c = n(a + c)$, proved by regrouping $2n$ rods. Books VII–IX have no algebra, so each rule of arithmetic has to be proved as a statement about parts and multiples. Book V proves the same law for magnitudes ([[5.1]]).
