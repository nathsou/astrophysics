---
title: Ex aequali
---
**Statement.** If $a : b = d : e$ and $b : c = e : f$, then $a : c = d : f$.

**Proof.** Alternate both hypotheses with [[7.13]]: $a : d = b : e$ and $b : e = c : f$. So $a : d = c : f$, and alternating once more gives $a : c = d : f$.

With fractions, it is the product rule: $\dfrac ac = \dfrac ab \cdot \dfrac bc = \dfrac de \cdot \dfrac ef = \dfrac df$. Euclid has no multiplication of ratios, so he chains alternations instead. The magnitude version is [[5.22]].
