---
title: Proportional numbers
---
Four numbers are **proportional**, $a : b = c : d$, when $a$ is the same multiple, the same part, or the same parts of $b$ that $c$ is of $d$. With the words of [[7.def.3]] and [[7.def.4]], this says that the fractions agree:
$$a : b = c : d \iff \frac ab = \frac cd \iff ad = bc,$$
the last form being [[7.19]]. For example, $6 : 9 = 4 : 6$, because each first number is two thirds of the second.

:::gap Two theories of proportion
Book V defines proportion for arbitrary magnitudes with Eudoxus' definition ([[5.def.5]]), which is designed to handle incommensurable ratios like $\sqrt2 : 1$. Book VII does not use it. It starts again with this simpler definition, which works because two numbers always have a common measure. Euclid never proves that the two definitions agree on numbers, yet [[7.19]] and later propositions quietly borrow results from Book V. Numbers are also magnitudes, so the agreement is true, but it is a gap in the book as written.
:::
