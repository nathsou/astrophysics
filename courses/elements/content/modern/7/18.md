---
title: Multiplying the same number keeps the ratio
---
**Statement.** $a c : b c = a : b$. In the figure, @A and @B multiply @C to make @D and @E, and the claim is $A : B = D : E$.

**Proof.** By [[7.16]], $a c = c a$ and $b c = c b$. So @C multiplies @A and @B to make @D and @E, and [[7.17]] gives $A : B = D : E$.

The only difference from [[7.17]] is the order of the factors. Since Euclid defines multiplication asymmetrically ([[7.def.15]]), he needs commutativity to pass from one to the other.
