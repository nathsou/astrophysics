---
title: Least numbers in a ratio are coprime
---
**Statement.** If $a, b$ are the least numbers in their ratio, then $\gcd(a, b) = 1$.

**Proof.** Suppose a number @C divides both. Let @D and @E be the quotients: $A = C \cdot D$ and $B = C \cdot E$ ([[7.def.15]]). By [[7.17]], $D : E = A : B$. But $D < A$ and $E < B$, which contradicts the minimality of $A, B$.

This is the converse of [[7.21]]. It is also the reason to reduce a fraction by dividing by a common factor: whatever common factor remains shows that the fraction is not yet least.

:::code Normalizing a rational type
A rational type needs a canonical form, so that equal fractions have equal representations. [[7.21]] and [[7.22]] say that the canonical form is the coprime pair:
```ts
type Ratio = { num: number; den: number }; // invariant: gcd(num, den) = 1
function ratio(n: number, d: number): Ratio {
  const g = gcd(n, d);                       // VII.2
  return { num: n / g, den: d / g };         // VII.33: the least pair in the ratio
}
```
Then $\frac ab = \frac cd$ if and only if the normalized pairs are identical ([[7.20]]).
:::
