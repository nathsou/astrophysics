---
title: Multiplication is commutative
---
**Statement.** $a \times b = b \times a$.

By [[7.def.15]], $a \times b$ (@C) is @B added to itself $a$ times, and $b \times a$ (@D) is @A added to itself $b$ times. That these are equal is not obvious from the definition.

**Proof.** @C is $a$ copies of $b$: $b$ measures $C$ according to the units in $A$. The unit @E measures $A$ according to the same units. By [[7.15]], the unit measures $B$ as many times as $A$ measures $C$. So $C$ is $b$ copies of $a$. By definition, $D$ is also $b$ copies of $a$. So $C = D$.

The picture behind the proof is the rectangle: $a$ rows of $b$ dots, read by rows or by columns. In the figure, the taller marks split @C into copies of @B and @D into copies of @A.

:::code Commutativity is a theorem
If multiplication is defined by recursion, as it is in Peano arithmetic or in a proof assistant,
```ts
const mul = (a: number, b: number): number => (a === 0 ? 0 : b + mul(a - 1, b));
```
then `mul(a, b) === mul(b, a)` is not true by definition. It has to be proved by induction, usually after proving distributivity. Euclid meets exactly the same situation and resolves it with [[7.15]], which is in effect alternation for the unit.
:::
