---
title: Multiplying by the same number keeps the ratio
---
**Statement.** $a b : a c = b : c$. In the figure, @A times @B makes @D and @A times @C makes @E, and the claim is $B : C = D : E$.

**Proof.** @B measures @D according to the units in @A, and so does the unit @F measure @A. So $F : A = B : D$ ([[7.def.20]]). In the same way, $F : A = C : E$. Hence $B : D = C : E$, and alternating ([[7.13]]) gives $B : C = D : E$.

In fractions, $\dfrac{ab}{ac} = \dfrac bc$: a common factor cancels. This is the rule behind reducing fractions, and [[7.20]]–[[7.22]] build on it.
