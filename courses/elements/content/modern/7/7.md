---
title: Subtracting equal parts
---
**Statement.** If $a = \tfrac1n b$ and $a' = \tfrac1n b'$ with $a' < a$, then $a - a' = \tfrac1n (b - b')$. In the figure, $AB = \tfrac1n CD$ and $AE = \tfrac1n CF$, and the claim is $EB = \tfrac1n FD$.

**Proof.** Euclid cannot divide, so he builds the answer from outside. Lay off @CG, the number of which @EB is the $n$-th part: $CG = n \cdot EB$ (dashed in the figure). By [[7.5]], adding $AE = \tfrac1n CF$ and $EB = \tfrac1n CG$ gives $AB = \tfrac1n GF$. But also $AB = \tfrac1n CD$, so $GF = CD$. Taking away the common @CF leaves $GC = FD$. So $EB = \tfrac1n GC = \tfrac1n FD$.

In modern terms this is $n a - n a' = n(a - a')$. Euclid proves it by adding, not subtracting, because addition is what [[7.5]] provides. The magnitude version is [[5.5]].
