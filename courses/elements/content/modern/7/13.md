---
title: Alternation
---
**Statement.** If $a : b = c : d$, then $a : c = b : d$.

**Proof.** @A is the same part or parts of @B that @C is of @D ([[7.def.20]]). By [[7.9]] or [[7.10]], @A is then the same part or parts of @C that @B is of @D, so $A : C = B : D$.

With cross-multiplication it is immediate: both proportions say $ad = bc$ ([[7.19]]). Euclid cannot argue that way yet, because [[7.19]] is proved *from* this proposition. The magnitude version is [[5.16]].
