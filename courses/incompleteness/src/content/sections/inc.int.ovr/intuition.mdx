## The general theorem

If $\Gamma$ is a consistent, axiomatizable theory in $\mathcal L_A$ which represents all computable functions and decidable relations, then $\Gamma$ is not complete: some sentence is **independent** of $\Gamma$. Gödel’s proof does more than show that one exists — it *constructs* one, $G_\Gamma$, from a description of $\Gamma$.

## The ingredients

| Ingredient | What it provides | Where |
|---|---|---|
| Computable functions | a precise notion of “mechanical”: the recursive functions | chapter 2, <Ref k="cmp:rec:pre:sec" /> |
| Arithmetization of syntax | formulas, substitution and derivations coded by numbers; “δ is a derivation of A” becomes a decidable relation of numbers | chapter 3, <Ref k="inc:art:int:sec" /> |
| Representability | $\mathbf Q$ derives the values of every computable function, so $\mathbf Q$ “knows” every decidable fact about syntax | chapter 4, <Ref k="inc:req:int:sec" /> |
| Diagonalization | the fixed-point lemma: a sentence equivalent to a statement about its own code | <Ref k="inc:inp:fix:sec" /> |
| Incompleteness | the Gödel sentence says “I am not derivable” | <Ref k="inc:inp:1in:sec" />, <Ref k="inc:inp:ros:sec" /> |
| Consistency is not derivable | the first theorem, formalized inside the theory | <Ref k="inc:inp:2in:sec" /> |

## A shortcut, and what it misses

<Ref k="inc:int:dec:sec" /> gets incompleteness without arithmetization, by a diagonal argument like the one for the halting problem. It shows that an independent sentence *exists*, but gives no way to write one down. That is the difference between the two routes: an existence proof versus a construction.
