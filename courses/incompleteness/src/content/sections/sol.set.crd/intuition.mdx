<Ref k="sol:syn:siz:sec" /> expressed that the *domain* is infinite or countable. This section does the same for a subset $s(X)$, and uses it to express that a set has size $\aleph_0$ or $\aleph_1$.

## Inf(X)

$$\exists u\,(\forall x\,\forall y\,(u(x) = u(y) \rightarrow x = y) \land \forall x\,(X(x) \rightarrow X(u(x))) \land \exists y\,(X(y) \land \forall x\,(X(x) \rightarrow y \neq u(x))))$$

Restricted to $X$, $u$ is an injection of $X$ into itself that misses an element $y$ of $X$: $X$ is (Dedekind) infinite. Each conjunct is needed. Without $\forall x\,(X(x) \rightarrow X(u(x)))$, $u$ could leave $X$, and finite sets would qualify: on $\{0, 1, 2\}$ take $X = \{0\}$ and let $u$ swap $0$ and $1$; $u$ is injective and $0 \neq u(0)$.

## Count(X)

$$\exists z\,\exists u\,(X(z) \land \forall x\,(X(x) \rightarrow X(u(x))) \land \forall Y\,((Y(z) \land \forall x\,(Y(x) \rightarrow Y(u(x)))) \rightarrow X \subseteq Y))$$

$X$ contains $z$, is closed under $u$, and is included in every set that contains $z$ and is closed under $u$: it is the *smallest* such set, $\{z, u(z), u(u(z)), \ldots\}$. So $s(X)$ is countable and non-empty. The last conjunct has to be $X \subseteq Y$, not $X = Y$: the whole domain always contains $z$ and is closed under $u$, so $X = Y$ would force $X$ to be the whole domain.

## Sizes

$\mathrm{Aleph}_0(X) \equiv \mathrm{Inf}(X) \land \mathrm{Count}(X)$ says that $s(X)$ is countably infinite. A set of size $\aleph_1$ is infinite but not of size $\aleph_0$, and each of its subsets is finite, of size $\aleph_0$, or as large as the set itself:

$$\mathrm{Aleph}_1(X) \equiv \forall Y\,(Y \subseteq X \rightarrow (\lnot\mathrm{Inf}(Y) \lor \mathrm{Aleph}_0(Y) \lor Y \approx X)) \land \mathrm{Inf}(X) \land \lnot\mathrm{Aleph}_0(X).$$

The disjunct $Y \approx X$ cannot be left out: $X$ is one of its own subsets, so without it the first conjunct would make $X$ finite or of size $\aleph_0$. (With the axiom of choice, an uncountable set has a subset of size $\aleph_1$; if that subset is as large as $X$, so is $X$.) The same pattern defines $\aleph_2$ and beyond.
