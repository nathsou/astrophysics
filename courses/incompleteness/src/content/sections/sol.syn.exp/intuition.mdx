A relation $R$ is **definable** in a structure if some formula $A_R(x, y)$ is satisfied exactly by the pairs in $R$. Quantifying over sets and relations lets second-order logic define relations first-order logic cannot.

</Added>

## Identity without =

Two objects are identical iff they belong to exactly the same sets. So

$$\forall X\,(X(x) \leftrightarrow X(y))$$

defines identity without using $=$: if $s(x) \neq s(y)$, the set $\{s(x)\}$ contains one and not the other. In fact $\forall X\,(X(x) \rightarrow X(y))$ suffices (the book’s problem) — the witness set $\{s(x)\}$ already does the job. This is Leibniz’s identity of indiscernibles, turned into a definition.

## Transitive closure

For a two-place $R$, its transitive closure $R^*$ relates $a$ to $b$ iff there is an $R$-path from $a$ to $b$. First-order logic cannot express this; second-order logic can, by describing $R^*$ as the **smallest** transitive relation that includes $R$:

$$B_R(X) \equiv \forall x\,\forall y\,(R(x,y) \rightarrow X(x,y)) \land \forall x\,\forall y\,\forall z\,((X(x,y) \land X(y,z)) \rightarrow X(x,z))$$

$$R^*(X) \equiv B_R(X) \land \forall Y\,(B_R(Y) \rightarrow \forall x\,\forall y\,(X(x,y) \rightarrow Y(x,y)))$$

$\mathfrak M, s \vDash R^*(X)$ iff $s(X) = R^*$. “Smallest” is expressed by quantifying over *all* competitors $Y$ — the characteristic second-order move, which reappears in the induction axiom (section 8.7).

<Callout title="Explore">
Choose a relation $R$ on a small domain and a candidate $X$: $R^*(X)$ holds exactly for the transitive closure. The $\forall Y$ runs through all $2^{n^2}$ relations — 512 on three elements.
</Callout>
