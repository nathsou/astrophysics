The language of arithmetic was designed to talk about $\mathbb N$, and the **standard model** $\mathfrak N$ interprets it as intended: $0$ is zero, $'$ is successor, $+$ and $\times$ are addition and multiplication, $<$ is less-than. This chapter asks what *other* structures make the same sentences true, or satisfy the axioms of $\mathbf Q$ or $\mathbf{PA}$ — and what that tells us about incompleteness.

</Added>

## Essentially the same

The book’s first example has nothing to do with numbers: the domain is the set of strings $\emptyset, a, aa, aaa, \ldots$, with $0$ the empty string, $s'$ the string $s$ with one more $a$, and $a^n + a^m = a^{n+m}$, $a^n \times a^m = a^{nm}$. Everything true in $\mathfrak N$ is true here, because the two structures differ only in *what* their elements are, not in how the operations relate them. Renaming $n$ as $a^n$ turns one into the other: they are **isomorphic** (section 7.3).

## Non-standard models

By the compactness theorem, every theory true in $\mathfrak N$ also has models that are *not* isomorphic to it (section 7.6). The difference shows up in the numerals. In $\mathfrak N$ every element is the value of a numeral $\overline n$. In a **non-standard** model some element is not: it lies beyond all the values of $\overline 0, \overline 1, \overline 2, \ldots$ — an “infinite natural number”.

## Why this matters for incompleteness

Take $\mathrm{Con}_{\mathbf{PA}}$, which says that no number codes a derivation of $\bot$ from $\mathbf{PA}$. By the second incompleteness theorem $\mathbf{PA}$ does not prove it, so $\mathbf{PA} \cup \{\lnot\mathrm{Con}_{\mathbf{PA}}\}$ is consistent and has a model. That model is not $\mathfrak N$ (where $\mathrm{Con}_{\mathbf{PA}}$ is true). In it, something satisfies “codes a derivation of $\bot$” — and since $\mathbf{PA}$ proves, of each standard $n$, that it does *not* code one, that something must be non-standard. The unprovable sentence is false only in models with non-standard elements.
