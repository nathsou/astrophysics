The semantic notions carry over word for word. A second-order sentence (no free variables of any kind) is **valid** if every structure satisfies it; $\Gamma$ **entails** $A$ if every structure satisfying $\Gamma$ satisfies $A$; $\Gamma$ is **satisfiable** if some structure satisfies it.

</Added>

## Same definitions, different logic

What changes is what these notions are like. Because second-order quantifiers range over all subsets and functions, there are valid second-order sentences that express substantial mathematics: Schröder–Bernstein (section 8.11) is one. And since the valid sentences of pure second-order logic include every $P \rightarrow A$ with $P$ the axioms of $\mathbf{PA}^2$ and $A$ true in $\mathfrak N$ (suitably generalised), the set of valid sentences is as complicated as arithmetic truth — no proof system can capture it (section 8.8).

## Checking on small domains

On a finite domain, satisfaction is computable by brute force. That can refute validity: one small structure where a sentence is false shows it is not valid. It can never establish validity: the sentence must also hold in all larger and all infinite structures. The workbench illustrates both directions with sentences whose status the book establishes by proof.
