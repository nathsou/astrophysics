<Added label="Added for this edition">

A structure for $\mathcal L_A$ is **standard** if it is isomorphic to $\mathfrak N$. The strings of $a$’s from the introduction form a standard model (once $<$, which the book leaves out there, is interpreted by comparing lengths); so does any structure obtained from $\mathfrak N$ by renaming its elements.

</Added>

## Every element has a name

In a standard model $\mathfrak M$, every element is the value of a numeral: $|\mathfrak M| = \{\mathrm{Val}^{\mathfrak M}(\overline n) : n \in \mathbb N\}$ (<Ref k="mod:mar:stm:prop:standard-domain" />). The reason: an isomorphism $g\colon \mathfrak N \to \mathfrak M$ must send $n = \mathrm{Val}^{\mathfrak N}(\overline n)$ to $\mathrm{Val}^{\mathfrak M}(\overline n)$, and it is surjective.

The converse is false (the book asks you to show this): $\mathbb Z_5$ has every element named by a numeral, but it is finite, so it is not isomorphic to $\mathfrak N$. What goes wrong is that different numerals name the same element — $\overline 0$ and $\overline 5$ both denote $0$.

## Named and distinct: standard

Add the axioms of $\mathbf Q$ and the converse holds (<Ref k="mod:mar:stm:prop:thq-standard" />): if $\mathfrak M \vDash \mathbf Q$ and every element is the value of a numeral, then $g(n) = \mathrm{Val}^{\mathfrak M}(\overline n)$ is an isomorphism. $\mathbf Q$ proves $\overline n \neq \overline m$ for $n \neq m$, so $g$ is injective; it is surjective by assumption; and $\mathbf Q$ proves the basic facts about sums, products and $<$ of numerals that make $g$ respect the operations. Moreover $g$ is the *only* isomorphism (<Ref k="mod:mar:stm:prop:thq-unique-iso" />): any isomorphism must send $0$ to $0^{\mathfrak M}$ and commute with successor.

## The domain is not the point

Any countably infinite set $M$ can be the domain of a standard model. Once $z \in M$ and a function $s$ are chosen as the interpretations of $0$ and $'$, the interpretations of $+$, $\times$ and $<$ are forced. The book shows what $s$ must be like: a bijection from $M$ onto $M \setminus \{z\}$, because sentences true in $\mathfrak N$ say that $'$ is injective, that $0$ is not a successor, and that everything else is. These conditions are necessary, not sufficient: $s$ must also reach every element of $M$ from $z$ in finitely many steps. (On $\mathbb N \cup \mathbb Z$ with $z = 0$ and $s(x) = x + 1$ on both parts, $s$ is a bijection onto the set minus $z$, but the copy of $\mathbb Z$ is never reached.)

<Added label="A slip in the printed text">

In the book’s last paragraph, if $s$ were not surjective there would be some $x \in M \setminus \{z\}$ “not in the domain of $s$”. The domain of $s$ is all of $M$; it should say *not in the range of $s$*. Then $\forall x\,(x = 0 \lor \exists y\, y' = x)$ would be false, as the book says.

</Added>
