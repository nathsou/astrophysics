A set is (Dedekind) **infinite** iff there is an injective function from it to itself that is not surjective. First-order logic can say this only about a function *symbol* $f$; second-order logic can say that such a function exists:

$$\mathrm{Inf} \equiv \exists u\,(\forall x\,\forall y\,(u(x) = u(y) \rightarrow x = y) \land \exists y\,\forall x\, y \neq u(x)).$$

$\mathfrak M \vDash \mathrm{Inf}$ iff $|\mathfrak M|$ is infinite, and $\mathrm{Fin} \equiv \lnot\mathrm{Inf}$ says the domain is finite.

</Added>

## Why Inf fails on finite domains

On a finite set, an injective function hits as many values as there are elements — all of them. So it is surjective, and no $y$ is outside its range. On $\mathbb N$, $u(n) = n + 1$ is injective and misses $0$. No first-order sentence expresses finiteness; no set of first-order sentences does either (compactness would produce infinite models).

## Countability

A set is **countable** iff there are an element $z$ and a function $f$ such that $z, f(z), f(f(z)), \ldots$ are all its elements. “All” is again the second-order move: every set containing $z$ and closed under $f$ is the whole domain.

$$\mathrm{Count} \equiv \exists z\,\exists u\,\forall X\,((X(z) \land \forall x\,(X(x) \rightarrow X(u(x)))) \rightarrow \forall x\, X(x))$$

$\mathfrak M \vDash \mathrm{Count}$ iff $|\mathfrak M|$ is countable. Every finite domain is: in Explore mode the workbench finds $z$ and $u$, and then runs through all $2^n$ sets $X$ to confirm that the only one closed under $u$ and containing $z$ is the whole domain.
