## About this course

The compiler, the visualisations and the text were written together as one TypeScript project: Vite, React and MDX for the pages, and the compiler under `src/compiler`. The test-suite compiles every example for every target at many configurations. It checks the output against the reference interpreter, and validates encodings and object files against GNU binutils and LLVM.
